Curriculum
32 weeks: from a clear problem to a working system
The curriculum builds in phases. Each phase returns to the same delivery questions with more demanding constraints, so nothing is learned once and forgotten.
Phase 1: Foundations
Weeks 1–4
Technical Track
Consulting Track
Python, Git, workflows, modern AI tooling
Understanding the business problem
Prompting patterns and APIs
Asking better questions
Basic system design
Framing a testable AI use case
You Produce
A first working AI tool, a clear problem statement, and an initial solution outline.
Phase 2: Core Build (IIT Modules)
Weeks 5–12
Technical Track
Consulting Track
LLM applications and workflows
Requirement discovery
Context engineering and RAG foundations
PRDs and solution design documents
Early evaluation, reliability, and application-layer patterns
Communicating scope, choices, and trade-offs
You Produce
A deployable AI system, an architecture view, and a record of key design decisions.
Phase 3: Deployment Depth
Weeks 13–20
Technical Track
Consulting Track
Advanced retrieval and RAG
Stakeholder alignment
Evaluation, monitoring, and iteration
Delivery planning and iteration cycles
Scale, reliability, and security failure handling
Managing feedback, scope change, and competing constraints
You Produce
A production-oriented system, deployment-ready documentation, and a clear ownership narrative.
Phase 4: Capstone & Mastery
Weeks 21–32
Technical Track
Consulting Track
MCP tools, policies, and production deployment
End-to-end engagement simulation
Multi-agent design
Case study writing
An SLM you train and serve yourself
Capstone presentation rehearsal
You Produce
Two full projects, five written case studies, a portfolio narrative, and a capstone system demoed live to the evaluation panel.
